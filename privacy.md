Oura Windows Sync is a personal application used solely by its owner to retrieve and analyze personal health and activity data from the Oura API.

Data is stored locally on the owner's Windows computer and is not sold, published, or shared with third parties by the application.

The application requests only the Oura API permissions needed for personal health and activity analysis.

The owner may stop data collection and delete locally stored data at any time.

This policy applies to the personal Oura Windows Sync application.
